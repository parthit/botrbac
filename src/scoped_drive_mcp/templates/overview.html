Connect an assistant

Every assistant uses the same server address. Add it as a custom connector or MCP server, sign in when the browser opens, and choose Allow. Leave any client id and secret empty.

Works with

  • Claude Settings → Connectors → Add custom connector. Works on web, desktop and mobile.
  • ChatGPT Turn on developer mode, then Settings → Apps → Create, with OAuth.
  • Dots Add the connector in ChatGPT first. Your dots can then use it.
  • Grok Connectors → New connector → Custom, or tell Grok Bot to add this server.
  • Muse Add a custom connector with this address.
  • Cursor Add an MCP server with this address.

Connected assistants, their wake-ups and Disconnect are in Settings.
