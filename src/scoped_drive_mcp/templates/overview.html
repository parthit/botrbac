Connect an assistant

Every assistant uses the same server address. Add it as a custom connector (in some apps it’s called an MCP server), sign in when the browser opens, and choose Allow. Leave any client id and secret empty.

Works with

  • Claude Settings → Connectors → Add custom connector. Works on web, desktop and mobile.
  • ChatGPT Needs developer mode: Settings → Apps → Create, with OAuth.
  • Grok Connectors → New connector → Custom, or tell Grok Bot to add this server.
  • Cursor Add an MCP server with this address.
  • Dots (dots inside ChatGPT) Add the connector in ChatGPT first. Your dots can then use it.
  • Muse Add a custom connector with this address.

Connected assistants, their wake-ups and Disconnect are in Settings.
