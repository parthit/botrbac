Bot RBAC is an access-control gateway that sits between AI agents, like Grok and Muse, and your accounts. It starts with Google Drive: you sign in, connect Drive, pick the files and folders an assistant may use, and this server refuses the rest. More services will follow.

Signing in asks Google only for your email. Connecting Google Drive is a second, separate step that asks for access to only the files you pick in Google’s file picker. Google keeps the rest of your Drive closed to Bot RBAC, and this server lets an assistant use only the items you allow. Contents of those items go only to an assistant you connect. They are not sold, used for advertising, or used to train a model.

The boundary is the product.

Three checks. No extra Google products.

  • Only what you allow. A connected Drive is visible to this server. An assistant cannot see it until you allow a file or folder. This server checks every call against that list.
  • Encrypted tokens. The Google refresh token is encrypted before it is stored. File contents are not kept on this server.
  • Revoke anytime. Untick an item, disconnect an app, disconnect a service, or remove Bot RBAC from your Google Account. New calls stop. Anything already sent is not recalled.
