Roles

A role is the list of tools an agent on your computer may use. Anything not on the list is blocked.

{{ terminal_tabs('roles') }}

How roles are used

  1. Make a role here (or use a built-in one). A starter fills in a sensible list you can edit.
  2. Give it to a computer by ticking the computer under “Use on” when you save the role, or on the Terminals tab: pick it in the Role column and press Change. A role does nothing until a computer uses it.
  3. Optional: narrow one run. botrbac run --role Reviewer -- claude gets only the tools both the computer's role and Reviewer allow. It can narrow, never widen.

Think of the computer's role as the most any agent there may do, and --role as a tighter limit for one session. A common setup is one everyday role per computer, such as Coding, plus a Reviewer role for runs that should only read.
