Privacy policy

This is the privacy policy for Bot RBAC, linked from the Google sign-in screen and from the home page.

Bot RBAC is an access-control gateway between AI assistants and services you connect. Google Drive is the first such service. Signing in only identifies you. If you then connect Google Drive, this server can see the same Drive you can, and you choose the files and folders an assistant may use. This server checks every call against that list. The list, and the assistant you connect, are the features of the app.

This deployment is run by the person who set it up. Any verified Google account can sign in, unless that person limited sign-in to a list of addresses. You sign in with your own Google account and tick your own files. The assistant uses that same account. Each person’s files stay separate. The support email shown on the Google sign-in screen is the contact for this app.

Google data we access

Google is asked for permission in two separate steps:

  • Signing in requests only openid and email, to read the account’s email address and whether Google has verified it. We use that to tell signed-in people apart. No Google token is stored at this step.
  • Connecting Google Drive, which you choose separately after signing in, requests only https://www.googleapis.com/auth/drive.file. Google then lets this app see, create, edit, and trash only the files you pick in Google’s file picker and the files this app creates. Google keeps the rest of your Drive closed to this app. This server further limits an assistant to the items you have allowed. Files the assistant creates inside an allowed folder are included.

We do not ask for your name, contacts, Gmail, or other Google products.

What an assistant can do depends on the role of the connection you gave it: search, reading text, creating files and folders, editing, renaming, and moving an item to Drive’s trash. This app has no tool to permanently delete a file, to change who a file is shared with, or to move a file between folders.

Notion data we access

Connecting Notion is optional, and only offered when this deployment has set it up. Notion then asks you which pages to share with Bot RBAC. This app can read only those pages and what is inside them, and {% if notion_create %}never changes or deletes them{% else %}never edits Notion{% endif %}. An assistant can read only the Notion pages you allow on Files, and what is inside them.{% if notion_create %} This deployment also lets an assistant you allow to edit add a new page under one of those pages; it never changes or deletes a page that already exists.{% endif %} The Notion access token is stored encrypted, like the Google refresh token. Page text is read only to answer an assistant’s request and is not stored. Disconnect Notion in Settings to delete the token and ask Notion to revoke it, or remove Bot RBAC in Notion under Settings → Connections.

OneDrive data we access

Connecting OneDrive is optional, and only offered when this deployment has set it up. Microsoft then asks you to let Bot RBAC read and edit your OneDrive files and see your name. Microsoft can’t limit that to some files, so this app lets an assistant reach only the OneDrive files and folders you allow on Files, and what is inside them. An assistant you let edit can add files and folders there and change or rename what is inside; this app never deletes, moves or shares OneDrive items. Your name or address is used only to show which account is connected. The OneDrive tokens are stored encrypted, like the Google refresh token. File contents are read or written only to carry out an assistant’s request and are not stored. Disconnect OneDrive in Settings to delete the tokens, and remove Bot RBAC at account.live.com/consent/Manage (personal account) or myapps.microsoft.com (work or school account) to end the permission at Microsoft.

How we use it

Google user data is used only to provide the features on the home page and in the dashboard:

  • Confirm the signed-in account.
  • Show the files you picked so you can allow them for an assistant.
  • Check each assistant request against that list.
  • Call Drive for an allowed item and return the result to the assistant you connected.

Those Drive calls use the Google account you signed in with, limited by Google to the files you picked. Allowing an item adds it to this server’s list, and that list is what an assistant can reach. An older connection that could reach the whole Drive is no longer used: it is deleted and revoked at Google when you reconnect or when the operator revokes old connections.

File contents are read from Drive only to answer that request. This server does not keep a copy, does not build a database of your files, and does not write contents, file names, or search text to the activity log.

What we store

  • The Google refresh token from connecting Google Drive, encrypted at rest, so the server can keep calling Drive after you close the browser. It is stored in Redis (Upstash) or Postgres, whichever this deployment uses.
  • The list you ticked: the Drive file and folder ids.
  • Access requests, kept for 7 days: a request id, the file id, a short description, the tool name, the connection name, your decision, and the file name only when your sign-in can already see that file.
  • An activity log of the last 500 events: time, tool name, allow or deny, and ids. The same lines go to the host’s logs. They do not include file contents.
  • A signed session cookie in your browser for about 8 hours. Signing out deletes that cookie. It does not contain your files, and signing out does not delete the stored refresh token or the list you ticked.
  • If an assistant connects with OAuth: the name it registered and the tokens for that connection, so you can disconnect it.
  • Mailbox text between two of your own assistants, kept for 14 days. The text is encrypted with the same key as the refresh token. Another person’s assistant can’t send text to yours.

The app is served over HTTPS. Drive calls and the stored token use that encrypted connection and the encrypted record above.

Who receives it

Google holds your files and handles sign-in. The assistant you connect receives the tool result for items you allowed, including file text when it reads a file. That assistant is a separate service. Sending the result there is the feature you turned on by connecting it and ticking those items. What the assistant does next is covered by its own terms.

The app runs on Vercel. The encrypted token, the list you ticked, requests, activity log, and mailbox text are stored in Upstash Redis or Postgres so the gateway can run. File contents are not stored with them.

Vercel also measures how fast pages load and how many times each page is viewed (Vercel Speed Insights and Web Analytics). These use no cookies. What is sent is the page’s address with ids and search text removed (for example /requests/:id), the browser, device type, country and load timings. File names, file contents, your email address and Drive ids are not sent.

Limited use

Bot RBAC’s use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

The use of information received from Google Workspace scopes will adhere to the Google User Data Policy, including the Limited Use requirements.

We do not sell Google user data. We do not transfer it to advertising platforms, data brokers, or information resellers. We do not use it for advertising or to determine credit-worthiness or for lending. We do not use it to create, train, or improve a machine learning or artificial intelligence model.

We do not pass Google user data to anyone other than the assistant you connected, except to keep the service secure, to comply with the law, or as part of a transfer of this deployment after you agree. People do not read your file contents through this server unless you ask, or it is required for security or by law.

Manage or delete your data

  • Remove an item in the dashboard to take it off your list. If that item was shared with an older assistant account, the share is removed too.
  • Disconnect an assistant on the dashboard overview. That deletes the tokens stored for that connection.
  • Disconnect Google Drive in Settings. That deletes the stored refresh token and asks Google to revoke it.
  • Remove Bot RBAC at Google Account permissions. Google then stops accepting this app’s sign-in, so the stored refresh token can no longer call Drive.

Access requests expire after 7 days. The activity log keeps only the latest 500 events. Signing out ends the browser session and leaves the stored sign-in and your list in place, so an assistant you already connected keeps the access you granted until you remove it or disconnect the assistant.

Bot RBAC is not directed at children under 13 and does not knowingly collect their information.
