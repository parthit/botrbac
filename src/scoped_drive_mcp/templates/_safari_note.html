{#- Safari blocks Google's cookies inside the picker's frame while "Prevent cross-site tracking" is on, and Google then shows "Can't access your Google Account". This page can't see inside that frame, so ui.js shows the note to every Safari visitor. -#}

Using Safari? Google’s file picker can’t load while Safari’s Prevent cross-site tracking is on. Turn it off in Safari → Settings → Privacy while you pick, then turn it back on: files you’ve picked stay picked. Or use another browser.
