Terminal

Control what AI agents on your computers can do. Works with any agent that supports MCP: Claude Code, Codex, Cursor, Gemini CLI and others.

Get started

  1. Install: uv tool install botrbac
  2. Log in: botrbac login, then approve the code on this site.
  3. Add botrbac gateway to your agent as an MCP server.

Bot RBAC only controls tool calls that go through it. It stops an agent from going around your rules; it cannot stop someone who owns the computer from removing it.
