Get started

  1. Install: uv tool install git+https://github.com/parthit/botrbac
  2. Log in: botrbac login --server {{ request.base_url | string | trim('/') }}, then approve the code on this site.
  3. Put your agent's tool servers behind Bot RBAC: botrbac wrap claude-code (or cursor, gemini), or add botrbac gateway as an MCP server yourself.
  4. Optional: eval "$(botrbac shell-init)", then start an agent with a narrower role: claude --botrbac --role reviewer.

Bot RBAC only controls tool calls that go through it. It stops an agent from going around your rules; it cannot stop someone who owns the computer from removing it.
